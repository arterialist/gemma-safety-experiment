What the edit changed

Inside the model, "refusing" is a single direction, like a compass needle pointing at "I cannot". We measured that direction from 64 harmful and 64 harmless questions, then erased it from layers 12 to 24. No retraining.

What the "no" direction makes the model say

Push the model along the direction we erased and these are the words it wants to write first:

"I" in English, Hindi, Chinese, Tamil, Vietnamese, Bengali... The start of "I cannot help with that", in every language.

For experts: why the textbook edit leaks, and how this one closes it

Gemma 3 multiplies every attention and MLP output by (1 + w) in a post-norm before it joins the residual stream. Projecting the refusal direction out of the weight matrix alone leaves a leak, because the post-norm rescales it back in. Mapping the direction through diag(1 + w) first closes the leak. Numbers are recomputed from the two checkpoints on disk when the server starts.

The edited model writes it. Its alarm still rings.

Same question to both models. Before either writes a word, we read a harm alarm at layer 11. The edit starts at layer 12, so the alarm reads both models the same way. If it rings, a safe app would block the answer.
